## What titles get traction

All high-scoring posts follow a tight formula:

> **"[Name], [one-line concrete benefit] for [specific audience]"**

- OzBrain: "shared brain for knowledge between agents and your team"
- Proliferate: "open-source, self-hostable Codex for any coding agent"
- Pgbot: "A 5.9 MB read-only Postgres tool for humans and agents"

Notice:
- Size in the title when it's small (5.9 MB).
- "open-source, self-hostable" as trust signals.
- Concrete audience: "humans and agents", "coding agent", "your team".

## Applied lesson for NeoBrowser

Current HN title used previously: "NeoBrowser: An MCP server that drives real Chrome with your logged-in sessions"

Tighter alternatives for a future Show HN retry:

- "NeoBrowser: A 6.4 MB MCP server that lets your AI drive your real Chrome"
- "NeoBrowser: Use your logged-in Chrome from any MCP client, no cloud browser needed"
- "Show HN: NeoBrowser — self-hostable browser agent that uses your real Chrome sessions"

Also worth noting: **small size is a feature**. Pgbot lead with "5.9 MB"; NeoBrowser should keep leading with "~6.4 MB single binary".

## Action

- Update future HN/PH/tagline copy to lead with size + local-first + real Chrome.
- Avoid abstract "drives real Chrome"; say what the user gets: "already logged in", "no cloud", "no new browser to install".
