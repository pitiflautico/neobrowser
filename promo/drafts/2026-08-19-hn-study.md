## Cuerpo (opción A)

I built an MCP server that drives a real Chrome with real logged-in sessions, and I wanted to know if the "genuine fingerprint" claim actually holds against live bot detection.

So I ran a reproducible harness against sannysoft/creepjs/nowsecure/deviceandbrowserinfo, comparing NeoBrowser, Playwright MCP and browser-use. Same machine, same Chrome major version, same run order.

Honest results:

- NeoBrowser passes bot.sannysoft 11/11 because it uses the host's real WebGL, UA and Client Hints.
- Playwright MCP's bundled Chromium fails the UA check ("HeadlessChrome") and scores 10/11.
- browser-use (Chromium) is closer to Playwright than to a real browser.
- Cloudflare blocks all three on the sites I tested — no tool honestly evades reputation-based challenges.

The harness, raw JSON and methodology are in the repo: github.com/pitiflautico/neobrowser/tree/main/bench

I tried to make the benchmark reproducible rather than tuned to make any tool win. If you spot a flaw in the methodology, tell me and I'll fix it.

## Cuerpo (opción B, más corto)

I wrote a small MCP server that drives your own Chrome instead of a bundled headless one, and I benchmarked it honestly against Playwright MCP and browser-use on live bot-detection sites.

Key result: on bot.sannysoft NeoBrowser is 11/11, Playwright MCP 10/11 (HeadlessChrome UA leak), browser-use somewhere in between. Cloudflare blocks all three equally — which is the honest thing to report.

Repo + harness + raw data: github.com/pitiflautico/neobrowser
