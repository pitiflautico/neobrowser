## Generic metadata

- **Name:** NeoBrowser
- **Tagline:** Drive real Chrome via CDP with your logged-in sessions — genuine stealth, bot-wall aware.
- **Short description (≤260 chars):** NeoBrowser is an open-source MCP server that drives your real Google Chrome over CDP. Agents browse, click, fill forms, upload files, and reuse your existing logins without spoofing fingerprints.
- **Long description:** NeoBrowser gives AI agents a real Chrome browser via the Chrome DevTools Protocol. Unlike headless automation, it can run against the user's own Chrome profile, importing cookies origin-scoped from the OS keychain so logged-in sessions just work. Every mutating tool returns a verified-action envelope with before/after evidence, domain rules and human-approval gates keep the agent on a leash, and the renderer sandbox is never disabled by default. A single ~6 MB Rust binary with 67 tools.
