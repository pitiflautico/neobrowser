**Name:** NeoBrowser

**Tagline:** MCP server that drives your real Chrome with your real logged-in sessions

**Description:**
```
NeoBrowser is an open-source MCP server that lets AI agents use the web through your real Google Chrome browser. Unlike headless browser tools that launch a fresh, fingerprintable Chrome and hit login walls, NeoBrowser drives your actual browser — with your real sessions, real fingerprint, and real trust.

Key features:
- Real Chrome over CDP, not a bundled headless clone
- Optional reuse of your logged-in sessions (opt-in cookie decryption via OS keychain)
- Genuine stealth: passes bot.sannysoft with the host's real fingerprint
- Bot-wall detection for reCAPTCHA, Turnstile, consent gates, rate-limits
- 67 tools: navigate, forms, upload/download, multi-tab, search, screenshots, playbooks
- Single ~6.4 MB static Rust binary, MIT licensed
```
