I ran two MCP browser tools against live bot detection. Here's the honest table.

August 19, 2026 · Daniel Perez Pinazo · reproducible: python3 bench/study.py

Every MCP browser tool claims to work. Fewer publish what happens when they meet an actual bot detector. So I took the two tools I can run side by side — NeoBrowser (drives the real Chrome binary via CDP) and Playwright MCP (Microsoft's, headless Chromium) — and pointed both at public detection sites. Same machine, same IP, two runs per cell, nothing tuned to make either win.

The table

What this actually shows

Fingerprint consistency is real and measurable. Playwright MCP's headless Chromium leaks HeadlessChrome in its User-Agent — the first thing any fingerprint script checks. NeoBrowser runs the genuine Chrome binary with a real version-matched UA, so every sannysoft check passes with the host's true fingerprint. That was the design bet: no spoofed values, because every spoof is a potential mismatch.

Real Cloudflare beats both. nowsecure.nl challenged and blocked both tools on both runs. Interactive challenges (reCAPTCHA, Turnstile) plus IP reputation are a different game, and anyone who tells you their headless tool just sails through from a datacenter IP is selling something. NeoBrowser's answer is detecting the wall and telling the model — not pretending it isn't there.

Playwright MCP is genuinely faster. 3–5× on navigation. NeoBrowser pays for forcing compositor frames so deferred content actually renders before reading. If your pages are static and speed is king, that's a fair reason to pick Playwright MCP.

What this does NOT prove

N=2 per cell, one machine, one residential IP, no proxy rotation. Test sites are proxies for detection, not production defenses. Playwright MCP ran headless (same as our previous comparison); headed mode might score differently. CreepJS showed no readable trust score in either tool at capture time — reported as "not read", not as pass or fail. One nuance we disclose: NeoBrowser exposes navigator.webdriver as undefined (absent) rather than stock Chrome's false; nothing penalized it here, a stricter detector might.
